# SPECTRA Visual Intelligence

面向团队内部研究与阶段性展示的视觉行业情报工作台。

- [查看当前情报界面](./index.html)
- [查看 2026-08-19 阶段性交付说明](./DELIVERY_20260819.md)

当前版本已实现采集、结构化、人工事实审核、核心事件写作、质量检查、网页生成及独立发布与钉钉推送。正式运行支持增量采集、检查点恢复和失败降级，以官方公告、论文、财报及已授权微信公众号为主要入口。人工审核与发布确认仍需操作；连续多日交付稳定性需持续验收。运行说明见 [Agent 文档](./spectra_agent/README.md)。
