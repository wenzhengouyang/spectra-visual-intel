# 采集与模型资讯整合

- 官方 AI 博客原先使用视觉生成关键词，导致通用模型、Agent 内容在入池前丢失。DeepMind/Hugging Face 复用现有模型关键词组，NVIDIA 生成式 AI 分类复用产品关键词组；微软战略源与工作 AI 组补充 Agent/model 等主题。不取消窗口、标题与下游事实门禁。
- RSS 健康结果记录窗口外、日期缺失、标题白名单未命中、标题排除、主题未命中计数及最多 12 个窗口内被拒样本。零产出不再一概归结为无更新。
- 模型相关资讯投影来自日报 `news_briefs`（同一 candidate_id），只收通过转写校验且有来源链接的条目，按模型名匹配。不从该文本更改版本和日期。与日报共用发布门禁。
- 官方目录采集沿用 `scripts/model-universe.py`，通过现有 daily_runner 巡检异步启动，不增设定时任务。独立内核锁、20 分钟超时、30 分钟退避、每日最多两次尝试；失败显示需关注，不阻塞日报。
- 官方快照与待核验状态保存在生产 data/model-universe，页面变化不等于版本发布。已有 apply 流程仍要求官方快照、证据原句与 reviewer；成功后清除对应模型待核验项。首次基线需核验，不冒称全部目录已更新。
- 进度页呈现采集状态、错误数、待核验数、最近采集、最近目录核验和日报关联数量。无核验记录时明确显示尚无新核验。
- 今天仍不发送钉钉。部署与测试通过不等于次日定时全链路验收通过。
