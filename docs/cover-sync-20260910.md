# 四张头图补齐与生成范围修复

根因：前端 coreEventIndex 使用 core_event 或 industry_signal，生成、审图和质量闸门仅检查 core_event。短讯版有行业信号卡片却跳过全部头图。

已用 requires_cover 统一后端三个环节，更新自动任务范围。恢复生成队列时保留真实生成元数据与匹配指纹的审批，避免被模板默认封面替换。

2026-09-10 Imagegen 实际生成及看图审核：

|稿件|配图与审核依据|
|---|---|
|OpenWAM|透明可组合模块连接空间场景、动作轨迹和机械臂，符合模块化世界动作模型主题；无性能数据或实拍冒充。|
|机器人语言迁移|希腊字符与拉丁字符汇向机械臂操作，符合跨语言机器人策略主题；无虚构成绩。|
|VeriScene|证据照片映射实体房间与空间线框，符合从证据重建场景主题；无真实案件、伤亡或虚构文字。|
|图像模型更新|同一陶土鸟在不同背景与光线下呈现，符合图像编辑保持主体的一般主题；作为概念插画，不是产品截图。|

前三张本轮由内置 Imagegen 生成，第四张采用同日已实际生成的图片。提示词围绕以上主体、行为与关系，统一 16:9、居中安全区、深色克制配色，避免产品实拍或真实性能指标。提示主题、图片SHA256与 Agent 审批记录保存在该期 image-generation.json、image-review.json；原始输出保留，项目源图位于 assets/editorial 的 *imagegen-20260910.png。

验证：21 项图片生成、审核、质量与进度测试通过，含行业信号进入生成队列及审核、缺图阻止发布的回归。
