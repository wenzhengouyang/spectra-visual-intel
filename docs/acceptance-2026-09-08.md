## 结论

当前版本比今天原线上版本更可控，但尚不应宣布“无人值守稳定”。本地源码已修复运行互斥、状态回收、审核版本、配额、超时日志、图片审核、页面分区与最小语义评测等问题；238 项自动化测试通过。5 张图片已经欧阳文铮人工审核并绑定文件指纹，新终稿由本机 qwen3:8b 完成来源约束的 shadow 评测，5 篇均 pass；随后已显式发布到 GitHub Pages（提交 `32b8cf7`）。仍需用更多人工标注样本验证语义评测的误放行率。

## 四、最小自动语义评测

新增独立 shadow 模块，输入为原文、人工保留事实和最终稿；先做缺字段/缺原文确定性检查，再由模型判断主体、数字、时间、限定、因果、夸大和来源归因。结果为 `pass/rework/manual`，包含问题位置、证据、修改要求与内容版本。只复用同版本 pass；返工最多 0–2 次，且返工不能改变证据和事实。

四条回归路径均通过：正确内容通过、错误内容返工、缺证据转人工、达到返工上限停止。当前仍是 shadow，`automatic_approval_enabled=false`；主流程会被 `rework/manual` 阻断。返工上限原语已实现并测试，但 Writer 自动改稿回调尚未接入，当前 rework 会明确停下，不能宣称自动返工闭环已经完成。

真实数据对照结果：摘要投影修复前的旧终稿评测按版本规则自动失效；图片审核后，新终稿重新评测。5 篇均返回 `pass`，总耗时 267.166 秒，输入 19,755 tokens、输出 75 tokens、合计 19,830 tokens。没有把原文发送到外部云模型。目前样本仍不足以证明模型不会误放行。
