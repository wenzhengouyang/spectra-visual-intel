# 独立账号与个人记录

账号版入口：<http://127.0.0.1:8012/>。无需钉钉应用、手机号、邮箱或外部登录配置。

## 使用

1. 点击右上角“登录 / 注册”，填写 3–32 位用户名（字母、数字、点、下划线、短横线）和至少 12 位密码，选择“注册新账号”。
2. 登录后，关注领域、有用/不相关反馈、收藏与最近阅读保存到个人账号。另一浏览器登录同一账号后会读取同一份记录。
3. 原有访客偏好不会自动写进账号。点击“导入本机关注与反馈”明确同意后才合并；退出后恢复当前浏览器的访客偏好。
4. 不同端口是不同浏览器存储空间。原 4174/8010 入口的偏好需先通过账号菜单“导出本机偏好”，再到账号版使用“导入偏好文件”。
5. 账号菜单可修改密码，修改后其他设备的会话失效。当前没有邮箱找回；请使用密码管理器保存密码。

## 已实现边界

- 免登录浏览；普通成员只读写自己的记录，没有审核、发布或管理其他账号的接口。
- 用户隔离、数据库持久化、加盐 PBKDF2 密码哈希、HttpOnly 会话、7 天有效期、退出撤销会话、来源和 CSRF 校验。
- 版本冲突重取最新数据并合并本次操作；失败显示未同步与重试，待同步数据存在时提醒不要关页。
- 收藏/阅读保留最近 500 个条目；当前页面内的记录可打开。移出本期的历史记录保留，但账号面板尚未提供完整历史文章索引。
- 所有用户均为普通成员；编辑/管理员工作流仍沿用现有本机人工审核，不在账号功能中自动授权。

## 本机服务与数据

- 服务名：`com.spectra.visual-intel.accounts`，登录电脑后自动运行，仅绑定本机。
- 数据库：`~/Library/Application Support/SPECTRA/data/accounts.sqlite3`，不在公开静态目录中，文件权限 600。
- 日志：同一 data 目录下 `logs/accounts.out.log` 与 `accounts.err.log`。接口不记录密码、会话或个人内容。
- 安装脚本：`scripts/install-account-service.py`；代码按 `scripts/deploy-approved-ui.py --files ...` 选择性备份同步。
- 当前开放本机注册；移除服务参数 `--allow-registration` 可关闭新注册，既有用户仍能登录。
- 开发用临时账号服务位于 8011，正式可用入口为 8012，两者数据库分离。

## 团队跨设备上线

本机 localhost 地址不能从其他人的电脑访问。多人使用需将同一账号服务部署到常在线主机，以 HTTPS 域名提供网页和 API 的同源入口，配置 `SPECTRA_ACCOUNT_ORIGIN` 为准确域名，并备份账号数据库。现有 GitHub Pages 静态托管不能独立运行账号后端。

本轮没有公开暴露本机端口、购买域名、迁移公网托管，也没有发送钉钉消息。钉钉登录代码已移除，原有钉钉情报推送功能不受影响。

## 验证

`tests/test_account_server.py` 覆盖密码存储与更改、会话撤销、用户隔离、并发版本保护、持久化、CSRF、限流和私有路径拒绝。

`scripts/check-accounts.cjs` 使用临时数据库实际注册测试用户，验证双浏览器同步、显式导入、收藏/历史、退出和手机布局；不向正式数据库写测试账号。
