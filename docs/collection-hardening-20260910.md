# 采集加固：2026-09-10

## 已实现并测试

- 来源健康：来源名、状态、有效记录数、有 raw_text 条数、仅摘要条数、仅元数据条数、耗时、失败原因。正文存在不等于完整/可信，统一标记 body_validation=not_verified。历史记录缺字段显示未记录，不伪造零值。
- fetch_bytes 共享默认预算：180 次实际请求、1200 秒、请求超时 30 秒、同域间隔 1 秒、响应上限 10 MiB；404/401/403 等不反复重试，429 保留有界 Retry-After。SDK/外部进程仍由单来源 300 秒总超时约束，不宣称计入 HTTP 次数。
- 每完成一个来源原子保存 .checkpoint.json；同配置、同采集窗口复用成功来源，仅重试失败来源。输出目标不同或窗口变化不会错误复用。
- 综合标题按原文分段，仅保留唯一匹配分类的一段，替换混合摘要；多个同类事件或未知分类先不发布。当前关键词映射只覆盖基础模型、Agent、具身三个方向；不改写已批准的历史事实。
- NewsCrawler 去掉 shell=True；外部提取 URL 拒绝 file、凭据、回环和私有字面 IP；提取器 JSON 输出不能通过符号链接越出临时目录。
- 完整回归 305 项通过，含本机真实 HTTP 404、429、超时测试和断点恢复测试，无外部采集、模型消耗、发布或推送。
