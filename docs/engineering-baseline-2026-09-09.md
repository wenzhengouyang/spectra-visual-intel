## 纳入范围

### UI

- 保留 `总览` 为默认入口。
- 一级频道固定为：本期精选、模型与前沿、能力与指标、产品与商业、内容与文化、团队与人才。
- 每个频道直接展示少量“主要内容”按钮，旧分类统一收进一个折叠的 `筛选` 入口。
- 核心事件继续使用头图；短讯不展示头图。
- 补齐当前导航与频道按钮的可访问选中态。

### 可靠性

- 无有效执行租约且无进展的任务统一识别为 `interrupted / blocked`。
- 自动恢复未耗尽时复用检查点；耗尽后明确转人工或降级，不再循环提示重试。
- 运行时间戳变化不再误判为内容变化；事实、正文、审核和文章变化仍会使旧评测失效。
- 429 遵循 `Retry-After` 或受限指数退避；WeRSS 异常进入冷却，不再每天反复整窗补采。

## 恢复方式

1. Git 代码恢复到标签 `spectra-baseline-2026-09-09`。
2. 从发布归档 `daily-20260909-<commit-short>.tar.gz` 解压今日审核、检查点和生成产物。
3. 运行 `spectra_agent/install_local_runtime.py --copy-only` 同步 runtime。
4. 执行 `status` 检查；需要继续时再运行 `resume --retry`，已完成且版本一致时应返回 `nothing to resume`。

归档生成后应同时保存 SHA-256；恢复演练必须在临时目录完成，不覆盖正式运行目录。
