# 短讯版发布规则

没有核心事件且存在短讯或行业信号时，允许以短讯版进入后续校验。
无任何内容时禁止发布空报告。可用 publication_quality.allow_brief_only 关闭兜底。

短讯版仅豁免核心事件数量下限。来源、日期、中文表达、语义、评测与发布检查继续生效；不会把短讯升级为核心事件。待审核条目必须先经过既有隔离流程，不允许直接带入发布。

页面注明短讯版并隐藏空核心事件分组。进度页显示短讯版的当前处理阶段。短讯不强制配图，保留引用的非展示图片不进入核心封面审核。

同一期补入审核通过的核心事件后，应重新生成并校验再发布，保留原审核指纹和既有发布归档。通知发送仍是独立动作，不因恢复任务而自动重发。
